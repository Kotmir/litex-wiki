# Как начать играть?

Пошаговый гайд — от заявки до первого входа на сервер.

## Шаги

### 1. Подайте заявку в Discord
Перейдите в наш [Discord](https://discord.gg/litex), откройте канал **📝・подать-заявку** и отправьте анкету.

::: warning Требования
- Возраст **13+**
- Аккаунту Discord **от 7 дней**
:::

### 2. Прочитайте правила
Внимательно прочитайте правила сервера в канале **📕・правила** (или в разделе [Правила](/rules) на вики).

### 3. Дождитесь проверки
Ожидайте проверки заявки от наших хелперов. При необходимости вас пригласят в голосовой канал `Проверка 1 / 2 / 3`.

### 4. Зайдите на сервер
После одобрения заявки запускайте Minecraft версии **Java 26.2** и заходите по IP:

```
mc.litex.tech
```

### 5. Зарегистрируйтесь
Введите команду `/register` в чате игры и следуйте дальнейшим инструкциям на экране.

### 6. Добро пожаловать!
Добро пожаловать на Litex! Приятной игры :)

::: tip Хотите больше атмосферы?
Загляните в [Моды и Сборка](/mods) — там рекомендуемые клиентские моды.
:::
