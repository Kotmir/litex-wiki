# Рекомендуемые моды и сборка

Клиентские моды для полного погружения на сервере. Все они необязательны.

| Мод | Что делает |
| --- | --- |
| **Simple Voice Chat** | Пространственный голосовой чат прямо в игре |
| **Custom Player Models (CPM)** | Кастомные модели персонажа |
| **Emotecraft** | Анимации и эмоции игрока |
| **Female Gender Mod** | Кастомизация модели игрока |
| **PatPat** | Возможность погладить других игроков и мобов (`Shift` + `ПКМ`) |

:::
